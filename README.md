# 节奏长跑 · Rhythm Run 3D

一个用键盘就能玩的 3D 卡通长跑小游戏：**A / D 左右交替踩步**，每次点击的间隔越均匀越省力；路上要跳过障碍、在补给点喝水吃香蕉，还能捡道具、朝前面的对手扔水瓶。和三个 AI 对手一起跑完 1000 米，抢第一。

纯前端静态页面，零构建、零运行时依赖（three.js 已内置在 `vendor/`），双击 `index.html` 就能玩。

## 玩法

### 键位

| 操作 | 说明 |
| --- | --- |
| `空格` | 起跑（倒计时中按）/ 跳跃（跑步中按，越过障碍） |
| `A` / `←`　`D` / `→` | 左右脚交替踩步（同侧连点会「错步」，扣体力） |
| `↑` / `W` | 补给点喝水（水分补满，得到一个**空水瓶**） |
| `↓` / `S` | 补给点吃香蕉（体力 +28，得到一个**香蕉皮**，但要慢跑一段） |
| `1` `2` | 使用对应道具槽 |
| `R` | 重开一局 |
| `M` | 静音 |
| 鼠标 / 触摸 | 点画面左半边 = 左脚，右半边 = 右脚；左下圆形按钮 = 跳跃；底部补给条可直接点左右两栏；右下两个道具槽可直接点 |

> **键盘没反应？** 先点一下画面。在预览面板 / iframe 里，键盘焦点默认在页面上层，页面收不到按键；点一次画面把焦点拿进来就正常了。标题页超过 3.5 秒没收到按键会出现橙色提示，跑步中如果键盘始终没响应，左上角还会常驻一条「键盘未响应 · 点画面左右两边来跑」，用鼠标也能玩完整局。
>
> 另外键位判定用的是 `event.code`（物理键位），中文输入法开着也能正常跑。

### 起跑：越接近「GO」越猛

按空格开始 3.2 秒倒计时，倒计时结束的瞬间要**再按一次空格**起跑：

- 距离 GO 的时刻越近（±0.5 秒窗口内）→ **起步加速越强**，速度从 4 起步，完美起跑能直接顶到 16 km/h 并额外获得 1.4~2.9 秒的加速
- 倒计时还剩 0.62 秒以上就按 → **抢跑**，0.55 秒内速度被摁住
- 一直不按 → 起步质量只有 15%

### 三条数值

1. **体力上限（金色）**——决定最高速度（16 ~ 26 km/h）。会随着跑动缓慢下降，越到后面越跑不快；吃香蕉能回一点。
2. **体力（绿色）**——每一步都在消耗，同时每秒快速回复（18/s），所以它会上下起伏。
   **判定的不是「踩在某个节拍上」，而是「每次点击的间隔是不是差不多」**：系统记着你最近的平均间隔，某一下跟平均值的偏差够小就算稳住，这一步的体力打 0.78 折；连着稳住还会叠「节奏稳 ×N」。忽快忽慢、抢拍、同侧连点都会让体力掉得明显。
3. **水分（蓝色）**——随时间一直掉，掉光后体力回复变慢、消耗变高。每 200 米一个补给点，别连着漏掉。

体力上限归零会**力竭退赛**，所以别一路狂点：快一点只多一点点速度，但体力和体力上限都会烧得很快。

### 障碍与跳跃

赛道上有三种随机障碍（每 56~88 米一个，会自动避开补给点前后 36 米）：

| 障碍 | 处理 |
| --- | --- |
| 跨栏 hurdle | 空格跳过 |
| 锥桶 cone | 空格跳过 |
| 水坑 puddle | 空格跳过（踩到会「踩水坑了！」并减速） |

跳跃滞空 0.62 秒。距离障碍 48 米内 HUD 会弹出「障碍 XXm · 空格跳过」预警，16 米内转红。跳早跳晚或干脆没跳，撞上就掉到 38% 速度。

### 对手

三个 AI 对手（阿虎 / 小鹿 / 老陈）同场竞技，各有不同的基础速度、跳跃成功率（0.46~0.78）和偷袭倾向（0.28~0.40）：

- 会自己跳障碍，跳不过也会撞
- 经过补给点时有概率顺手朝你扔水瓶，让你**减速**
- 对手踩到香蕉皮会摔
- 顶部进度条上会用对手的配色标出他们的小点，右上角 `第 N 名 / 4`

### 道具赛

有 2 个道具槽（`1` `2` 使用）：

| 道具 | 来源 | 效果 |
| --- | --- | --- |
| **加速** | 补给点随机（55%） | 5 秒内速度 ×1.26 |
| **干扰** | 补给点随机（45%） | 命中前方 48 米内最近的对手：**3.5 秒内左右键位互换成 `↑` `↓`**，屏幕泛紫并提示「按键错乱」 |
| **空水瓶** | 喝完水自动获得 | 朝前方最近的对手投掷，命中减速 2 秒 |
| **香蕉皮** | 吃完香蕉自动获得 | 丢在自己脚下，后面踩到的对手打滑 1.7 秒 |

水瓶和干扰需要**前方 48 米内有对手**才能扔，扔不出去会提示「前面没人」。香蕉皮是往后放的，专治贴身追你的那位。

### 结算

名次决定评级：第 1 名 `S` 冠军、第 2 名 `A` 亚军、第 3 名 `B` 季军、第 4 名 `C` 完赛，力竭退赛 `D`。结算卡会列出用时、距离、平均配速、节奏稳定率、跳跃成功率、道具命中次数。

## 文件结构

```
index.html          页面 + 样式（两个 canvas：3D 场景 / 2D HUD）
vendor/three.min.js three.js r149（UMD 版本，已内置）
src/logic.js        游戏核心逻辑：纯函数，无 DOM 依赖，可在 node 里跑数值仿真
src/scene.js        3D 世界：角色骨架、对手、障碍、道具、地形、补给拱门、终点、粒子、相机
src/hud.js          HUD 层：状态条、进度与对手小点、名次、道具槽、跳跃按钮、补给按键提示、标题与结算
src/game.js         主循环、输入、音效
tune.js             数值平衡仿真（node tune.js）
```

## 开发

```bash
# 平衡性仿真：用真实 logic.js 跑完整比赛，对比不同手速/节奏的玩家与三个对手
node tune.js
```

调参都在 `src/logic.js` 顶部的 `C` 里（参考步频 `IDEAL`、稳定判定 `STEADY_DEV`、体力消耗 `COST_BASE`、回复 `REGEN`、速度上限 `VMAX_*`、起跑窗口 `START_*`、跳跃 `JUMP_*`、道具 `BOOST_* / JAM_* / SLIP_*` 等），改完跑一遍 `tune.js` 就能看到结果。

当前手感（`node tune.js` 实测，全程 1000 米；对手和障碍是随机生成的，多跑几次数值会小幅浮动）：

| 玩家 | 结果 |
| --- | --- |
| 稳如钟摆 | 146~147 秒完赛，**第 1 名**，体力最低 ~75 |
| 普通玩家 | 147~149 秒完赛，**第 1 名**，体力最低 ~71 |
| 手抖 / 忽快忽慢 | 152~156 秒完赛，**第 1~2 名**，中途体力见底 |
| 慢慢摇 | 210~212 秒完赛，第 4 名 |
| 疯狂乱按 | ~104 秒力竭退赛，撞 6~7 个障碍 |

也就是说：**稳住节奏能赢，快而不稳会被 AI 咬住，乱按直接退赛**。

镜头参数在 `src/scene.js` 顶部的 `CAM` 里，对手强度在 `src/logic.js` 的 `RIVAL_DEFS` 里。

## 技术要点

- 键位用 `KeyboardEvent.code`（`KeyA` / `Space` / `ArrowUp`…）而不是 `key`，中文输入法激活时 `key` 会变成 `Process`，用 `code` 才不会漏键。`key` 只作为老浏览器的兜底。
- 预览面板里页面跑在 iframe 中，键盘焦点不在页面内时 `keydown` 根本不会派发；标题页会检测「是否收到过真实按键」，超过 3.5 秒没有就提示点击画面，点击时顺手 `window.focus()` 把焦点抢过来。
- 角色没有用骨骼动画，而是用一组 `Object3D` 转轴做正向运动学：髋/膝、肩/肘按跑步相位摆动，膝盖在腿后摆时弯曲，配合躯干前倾和上下起伏。玩家和三个对手共用同一个 `buildRig()` 工厂，只是配色不同。
- 地形是程序化的：路面/草地/天空贴图用 canvas 现画，树木灌木按 `WORLD_SPAN` 循环回收，所以 1000 米赛道不需要重复建模。天空直接用 `scene.background` 铺程序化贴图，避免远裁剪面切出黑块。
- 障碍、香蕉皮、投掷物、尘土、火花都用对象池复用，跑完全程也不会触发 GC 抖动。
- 逻辑层（`logic.js`）完全不碰渲染，`tune.js` 直接 `require` 它做上万帧仿真来调平衡。
- 所有节奏判定与体力回复都走同一个「游戏内时间」（按帧累加，单帧最多 0.06 秒），掉帧时不会出现「判定用真实时间、回复用帧时间」两套时钟错位。
